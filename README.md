# 碳纤维复材铺层设计与仿真系统

纯前端单页应用，零外部依赖（无 CDN、无后端、无外部数据），浏览器打开即用，可离线运行。
全部示例数据（工程/材料/模具/铺层/实测曲线）均由程序生成。

## 打开方式

- 直接双击 `index.html`（支持 file:// 协议）；或
- `python -m http.server 8000` 后访问 http://localhost:8000

数据保存在浏览器 localStorage，顶栏"重置示例数据"可随时恢复出厂示例。

## 页面与功能

| 页面 | 功能 |
|---|---|
| 工程列表 | 在制/待评审/已归档三态流转，每次流转必填处理意见；归档即锁铺层，登记变更单解锁；同系列零件派生，谱系可回溯父工程 |
| 材料库 | 预浸料牌号力学参数 + 按卷库存（批号/幅宽/冷库库位）；出库累计晾置时长，80% 预警、超期锁定不可选；下料自动扣减库存，低于安全库存标红 |
| 模具 | 型面三维查看；按铺层累计厚度生成偏置补偿面；按模具材料 CTE 整体预缩放；UV 边界线圈定铺贴范围；偏置失败区域标红并可手填补偿量 |
| 铺层编辑 | 逐层选材料/角度(0/±45/90)/覆盖范围，复制/调序/删除；越界即时报警；铺覆模拟：剪切角云图预警（锁模角）、纤维流线箭头、剪口断开重铺、夹持点顺序、压实辊→逐层空隙率、相邻层拼接缝描边 |
| 仿真结果 | CLT 固化翘曲云图（变形可放大 1~500×，给出最大变形量及位置）；逐层残余应力；虚拟热电偶温度曲线 + 车间实测曲线叠图偏差；整模最高/最低温点及到达时刻；温差超公差时段列表 |
| 铺层优化 | 翘曲最小+重量最轻，角度离散档搜索，可中途停（结果不丢），帕累托前沿散点图，选中解一键回填新铺层 |
| 车间作业 | 激光投影文件按层导出（对齐模具基准点，含角度刻线/搭接边界），偏差超差重新校准；真空袋辅材裁片与密封胶条长度；抽真空保压计时+压降速率报警+检漏记录存档；每层铺贴工单（批号/角度/顺序号）扫码调阅 |
| 校验报告 | 全部校验项阈值可改，改动即自动重算；报告含仿真指纹，可导出 JSON |

## 确定性保证（核心设计）

- 仿真结果 = f(铺层参数, 模具, 材料)，纯函数计算（经典层合板理论 CLT + 解析温度场），无任何时钟/随机依赖；
- 所有"噪声"成分（实测炉温、空隙率涨落）由参数哈希做种子的伪随机生成，可复现；
- 每组铺层参数对应唯一**仿真指纹**（FNV-1a 稳定哈希），铺层页/仿真页/报告页均显示，参数一变指纹即变、结果自动重算；
- 校验报告读取实时阈值，阈值修改立即触发全量重算。

node test/smoke.js   # 引擎层：确定性/CLT物理合理性/几何/状态机（28项）

## 目录结构

```
index.html          入口
css/style.css       样式
js/util.js          确定性随机/稳定哈希/DOM工具
js/clt.js           经典层合板理论（刚度/固化曲率/残余应力）
js/geometry.js      参数化型面/偏置面/边界/剪切角场/流线
js/simengine.js     确定性仿真引擎（指纹缓存）
js/store.js         状态/持久化/示例数据/状态机
js/viewer3d.js      零依赖Canvas三维渲染器
js/charts.js        二维图表
js/p_*.js           八个页面
js/app.js           路由
```
